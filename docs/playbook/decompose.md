# decompose —— 拆解流程（playbook）

> 上游：schedule-app.md §1（粒度定律）/§7（两类长任务出鞘策略/Landing Gear）。

## 粒度阶梯

```
概念 「想去云南玩」     ← 快记捕获
  ↓ 拆解（AI）
任务 「订往返机票」     ← 有方向有时长感，还不可排
  ↓ 细化（AI + 澄清问答）
行动 「练 C↔G 和弦转换 20 分钟」 ← 一次能做完、时长明确、动词开头
  ↓ 排程
块   周三 19:00–19:20 + 行动 label
```

- **只排叶子**：叶子 = 动词开头、一次能做完、时长明确。父计划被要求排期时先下钻/先拆解。
- 深度 ≤3（概念→任务→行动）；车上场景用分解不搞嵌套。
- 时长估不出 = 澄清项进 open_items，不瞎猜。

## 两类长任务的出鞘策略

- **确定型（流水线：考驾照/办签证/旅行筹备）**：全量线性步骤以 Markdown Checklist 写入父计划 spec 尾部路线图块；**同一时刻只实例化 1 个活跃叶子**，后续步骤以文本休眠。叶子 done → 把 spec 中该行标 `[x]` 并具象化下一行（确定性接棒）。

  ```markdown
  ## 路线图
  - [x] 预约签证中心 (ACTIVE→已完成)
  - [ ] 整理材料清单 (ACTIVE)
  - [ ] 递交材料
  ```

  语法：`## 路线图` 节内 Checklist；当前步标 `(ACTIVE)`；完成步标 `[x]`。
- **探索型（涌现：写论文/学吉他/独立开发）**：不推演全流程（伪自律）。循环 = 发射**探针**（一个有明确产出的具体行动）→ 勾选后结论沉淀进父计划 notes → 下一步自然清晰则直接转化新叶；陷入认知真空则严禁直接挂起——自动生成 15 分钟梳理型火种（「梳理下一步方向」）。

## Landing Gear（启动第一步）

AI 细化行动时，必须在 plan.notes **首行**沉淀一句可立即执行的启动第一步（「打开 PDF 第 45 页第 3 题」）——行动之前的 60 秒是认知摩擦最大的时段。

## 收尾叶子 = 兑现奖励

decompose 的收尾叶子是兑现 reward_spec 的庆祝行动（动词开头、有时长），不是生硬的「复盘总结」。付出型限定见 clarify.md。
