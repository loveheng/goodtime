# dump —— 大脑倾倒（playbook）

> 上游：schedule-app.md §7（大脑倾倒冷启动，十轮拍板）。

## 场景

新用户首启不面对空白页：桌面端把脑中所有事、微信收藏、备忘录**整段**甩进对话框（「这是我脑子里所有想做的事，帮我理理」）。

## SOP

1. 整段文本 → 识别独立概念（一句一件事）；
2. 逐条拆分：剔除废话、提取标题（用户原始措辞原样保留）与初版 spec；
3. 琐事/≤30min 类免澄清直接给叶子行动；高阻力类挂 open_items 走 clarify；
4. **批量 add_plan** 入池（快记零负担口径：light/anywhere 默认）；
5. 汇报用护航式叙事：「清出 N 条，其中 3 条我标了重要。没有一条会被遗忘——它们都在愿望池里，被排期就是升格。」

## 纪律

- 零 app 端导入器、零新工具，全走 MCP 与自然语言解析；
- 不当场排程（先入池，排期是另一个回合的决策）；
- 涉他人的事项按 clarify.md 标注「该空闲系用户口述」。

## 零散信息三通道路由（背景草案 §4，2026-10-07 增）

倾倒文本里混着的常驻信息按性质分流，**不加第四个通道**：

| 信息性质 | 去向 |
|---|---|
| 人设/语气 | `identity_prompt`（仅用户自设，走 suggest_user_setting 建言） |
| 硬性常驻规则（「周五晚上不排深度工作」） | `user_rules`（同样建言） |
| 常驻画像叙事（过敏原/常住地/体力常态） | `upsert_background`（scope=global，受注入预算） |
| 行程软上下文（「这次主要看雪山，体力有限」） | `upsert_background`（scope=plan，挂计划） |

**背景兜底（三刀路由第④去向）**：无刚性时空锚点、非行动类的叙事信息落背景，绝不写成硬规则或硬排成块——分界判据=该信息是否产生刚性时空边界。

## 背景捕获纪律（2026-10-07 增）

- **捕获原子化，治理归并化**：一条记录=一个可独立成立、可独立删除的语义（判据=能否单独删掉而不损义），严禁 200 字叙述打包入库——「妈妈膝盖不好少走路」与「偏好慢节奏」拆两条分别落库，便于单独删除与单独挂日期窗；各原子允许引用同一段原文（raw_source_text 存相关片段，溯源不断）。
- **回显义务**：写完背景必须向用户显式回显（「已记录背景：妈妈膝盖不好——不对就说我改」），误写靠删除通道兜底，不设撤销子系统。
- **global 预算口径**：content 总字数按字符计 ≤400、条数 ≤8（命令层终态校验，只计 content——raw/tags 不进分子）；瞬态背景给 `applicable_dates`（单日 ISO 日期数组，一律日历日，如 ["2026-10-08","2026-10-09"]），缺省=长期，空数组按长期处理；窗超 14 天改长期（瞬态窗本就该短）。
- `raw_source_text` 存用户原话逐字，仅建档写入一次、永不覆盖（含后续再提炼同条记录）。
