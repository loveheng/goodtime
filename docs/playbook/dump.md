# dump —— 大脑倾倒（playbook）

> 上游：schedule-app.md §7（大脑倾倒冷启动，十轮拍板）。

## 场景

新用户首启不面对空白页：桌面端把脑中所有事、微信收藏、备忘录**整段**甩进对话框（「这是我脑子里所有想做的事，帮我理理」）。

## SOP

1. 整段文本 → 识别独立概念（一句一件事）；
2. 逐条拆分：剔除废话、提取标题（用户原始措辞原样保留）与初版 spec；
3. 琐事/≤30min 类免澄清直接给叶子行动；高阻力类挂 open_items 走 clarify；
4. **批量 add_plan** 入池（快记零负担口径：light/anywhere 默认）；
5. 汇报用护航式叙事：「清出 N 条，其中 3 条我标了重要。没有一条会被遗忘——它们都在愿望池里，被排期就是升格。」

## 纪律

- 零 app 端导入器、零新工具，全走 MCP 与自然语言解析；
- 不当场排程（先入池，排期是另一个回合的决策）；
- 涉他人的事项按 clarify.md 标注「该空闲系用户口述」。
