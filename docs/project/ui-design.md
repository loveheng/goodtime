# 拾光 UI 设计规范 · 心理层日程台账风格

> 拾光视觉与交互语言 **SSOT**。基调：Material 3 + 固定品牌色板（关闭动态取色）——拾光的视觉资产（香槟金 / 淡绿补给带 / 灰投影）是心理层的一部分，不能交给系统壁纸随机化。
>
> **本文零外引**：不挂钩外部文档、不使用外部代号（内部概念词一律降级为括号备注）；外部一律单向指向本文。
>
> **分工**：本文是**大面规范**（色彩/排印/标尺/术语映射/模块形态契约）——「哪个页面长什么样」与各页具体文案串不在此登记，页面布局稿 = `docs/design/ui-pages.md`（其单向指入本文，§9 承接各页文案清单）。
>
> **旧编号对照**（前身为 `docs/design/ui-spec.md`，2026-10-19 迁入；存量引用的旧节号按此换算）：旧 §0.4 文案词汇表 → §4（核心术语映射；页面级文案串 → ui-pages §9）；旧 §0.5 深色面板 → §1.2；旧 §6 渲染矩阵 → §5（旧 §6.5 物理约束 → §3.4）；旧 §1–§5 / §7–§9 为页面级内容（导航/引导/今日页/周月/清单/块浮层/交互流/空态）→ 已拆 `docs/design/ui-pages.md`（§1–§8 同序承接）。旧 §10 里程碑裁剪（施工过程，归 Git/蓝图）与旧 §11 拍板记录（拍板留痕归 schedule-app §11）不再保留。
>
> **总纲（三条，全程有效）**：① 界面只陈述事实、不审判用户（中性语言，见 §4 文案总则）；② 动效克制（全 app 仅三处，见 §3.3）；③ 视觉资产固定，禁动态取色与任意新色值。
>

## 1. 色彩 Token（心理语义驱动）

浅色为基线；深色经整体映射切换（§1.2），语义角色不变。色彩即语义：每个 token 对应一种心理/状态语义，禁装饰性用色、禁任意取新色值。

### 1.2 深色语义面板

双主题同值（本就是深底或高亮色）：`deepFocusBg/deepFocusText/sparkStroke/roamStroke/celebrationStroke/supplyBandStroke/overlapHint/safelineOn`。

换值仅十三项：`sparkBg #332C10`、`roamBg 90CAF9@12%`、`celebrationBg #3B3323`、`voucherBg #3A2F12`、`supplyBandBg #1E3324`、`freeFlowBg #1F2E1B`、`humanBlockBg 78909C@33%`、`fixedSlotBg #26292B`、`projectionBg #2A2D2F`、`missedAccent #3A2F1B`、`textPrimary #E3E2E0`、`textSecondary #9CA0A5`、`safelineOff #616161`。

实现取舍：全局激活面板——`ShiguangApp` 装配点经 `StColors.applyBrightness` 置位、业务代码只读（浅色基线逐值不变），而非 ThemeExtension；单窗口单主题下全部调用点零迁移，多窗口/动态取色出现时再扩展。

### 1.3 用色纪律

- 界面文案/结构用色只取本表 token；新增语义先扩本表并同步 tokens.dart，禁组件内直取任意色值。
- `missed` / `melted`（不渲染）/ `archived`（15% 淡出）三态视觉必须保持三档层次，红色系禁用于一切「未完成/未打卡」语义。

## 3. 布局标尺与物理约束

### 3.1 尺度基准

- **时间轴基准比例尺：1dp = 1min（60dp/h）**——常规作息聚焦窗（约 16.5h）总高 ≈990dp，单手 1–2 屏通览全天，认知负荷最低。
- **最小触控热区钳制：块渲染高度 clamp(min: 44dp)**（Material 最小触控目标）——物理时长 <44min 的块强制撑高至 44dp、内部单行居中排版（微型火种胶囊 5min 是主要受益者）。借用顺序：先借后置自由流动区/普通空白 → 仍不足则**向下溢出覆盖**（钳制块时间轴内 z 序最高 + 4dp 投影），被覆盖的补给带/块按真实 y 位渲染、可见部分走 §3.4 三级过滤——呼吸律补给带不被钳制清零。
- **主题模式**：设置页「外观」三档（跟随系统/浅色/深色，默认跟随系统）；深色下 Material ColorScheme 换 `fromSeed(brightness: dark)`，语义色板经 tokens.dart `StColors.applyBrightness` 整体切换（§1.2）。`theme_mode` 为 **uiOnly 设置键**：AI 经 update_settings 触碰即拒，外观是人的感官偏好。

### 3.2 层叠 Z 序

页面内容（时间轴/周/月网格/清单列表，Z=0）→ 快记 FAB（Z=20）→ 全局动作/块浮层 sheet（Z=30）→ 快记抽屉（Z=40，键盘吸附）。分级确认卡为 Column **内联件**（非浮层），不参与 z 竞争；FAB 与滚动内容底部重叠区以**滚动净空**化解（`tokens.fabClearanceDp=88dp`，末尾内容可滚出 FAB 覆盖区）；模态 sheet 与快记抽屉走独立路由天然在上。§3.1 钳制块「时间轴内 z 最高」为时间轴局部规则，与此并存。

### 3.3 动效（全 app 仅三处，其余零动画）

| 动效 | 规格 |
|---|---|
| 长按坍缩 | 300ms ease-out（块高收缩至 5min 等比，剩余释放为补给带） |
| 右滑融化 | 400ms（不透明度+上移消散，**绝不显红**） |
| 安全线点亮 | 250ms spring 单次 |

手势期间用 transform 不重排，守 60fps；禁整页 setState 驱动的动画。

### 3.4 手势与绘制的物理约束

- **手工块重叠分栏**：重叠只可能发生在 human 侧（AI 块被校验整单拒绝、投影属 human 硬墙）——同一时段重叠的块自动切 **50% 等宽双列**，重叠块边缘亮橙色 1dp 细线提示碰撞但**完全放行**（校验不对称「橙色提示」的渲染对应）。
- **手势防误触锁**：块上横滑触发须同时满足 **水平初位移 >20dp** 且 **|Δx/Δy| > 2.0**，不满足无条件交还外层垂直滚动；长按持续 **400ms** 触发（触发后播 300ms 坍缩动画），按住期间卡片呼吸压缩（scale 0.98）给出意图感知。
- **滑动卡点与触觉**：右滑融化过块宽 **45%** 吸附 + `HapticFeedback.mediumImpact`，松手执行消散，未过线弹回原位；左滑换乘过 **35%** 呼出换乘抽屉、原块弹回。
- **派生保护区三级绘制过滤**（防视觉噪点）：空隙 ≥30min 完整渲染（底色+虚线框+图标+文案）；15–30min 仅底色+居中图标（15dp 高度排不下可读文字，语义由图标承载、聚合数由双轨仪表盘表达，信息不丢）；**<15min 静默留白**（不渲染任何边框与装饰色）。

## 4. 文案术语映射（内黑话外白话）

> **原则**：底层代码、数据字段与设计文档内部保留概念词（括注形式），**用户可见界面文案零黑话**——平实、自解释、零认知负荷。三准则：**①动词优先于名词**（不说「形态」，直接说「只做 5 分钟」）；**②永远交代去向**（不说「消散/蒸发」，说「已放回清单待安排」）；**③系统是盟友不是法师**（越是大白话，减震与去负罪感越真实）。
>
> **本表范围是封闭的核心术语映射**（概念词 → 白话，跨页面稳定的翻译口径），不是各页字符串清单——页面级具体文案住 `docs/design/ui-pages.md` §9；新**概念词**入本表后再上屏，新**页面串**入 ui-pages §9 对应组再上屏。

### 4.1 状态与形态（科幻物理 → 生活直觉）

| 内部术语（不上屏） | 界面文案 | 说明 |
|---|---|---|
| 黄红火种（is_day_spark） | **今日核心** | 保留 🔥 图标；「今日核心 1 项」直指本质 |
| 微型火种态/坍缩（spark） | **5 分钟启动版** | 提示「已切换为 5 分钟启动版」而非「已坍缩为火种」 |
| 漫游主题态 | 不出现形态名，直接呈现活动 | 渲染弱底色+`~`，文案写活动本身 |
| 庆祝勋章态 | **犒劳时刻** | 「犒劳一下」贴近真实心理，无战争压迫感 |
| 能量补给带（supplyBand） | **留白缓冲** | 传达「这是属于你的安全休息时间」 |
| 自由流动区（freeFlow） | **自由支配时间**；聚合标签「自由留白」 | 大白话：「这段时间完全由你支配」 |
| 安全线徽章 | **今日底线守住啦** | 点亮提示全文见 ui-pages §9.1 |

### 4.2 手势与操作（玄学 → 明确预期）

| 内部手势 | 界面文案 | 消除的担忧 |
|---|---|---|
| 右滑融化（Melt） | **暂缓并收回清单** | 最大暗坑：杜绝「是不是彻底删了再也找不到」的误删焦虑 |
| 长按坍缩（spark） | **只做 5 分钟** | 用户立刻理解「被缩减到极低阻力状态」 |
| 左滑换乘（Swap） | **换件轻松的？**（抽屉标题） | 疲惫时的真实心态是「换件不费脑子的事」，不是坐地铁 |
| 沉浸中别理我 | **心流专注中 (+30m)** | 带共情温度，且说明会顺延后续安排 |
| 现实熔断键 | **遇到突发情况？**（sheet 标题，见 ui-pages §3.6） | 「熔断」是金融词，徒增紧张 |

### 4.3 抽屉与长任务（系统架构 → 具象行动）

| 内部术语 | 界面文案 | 说明 |
|---|---|---|
| 启动第一步（Landing Gear） | **马上开始** | 用户只需一眼看到「手头第一件事干嘛」，不需要知道起落架 |
| 悬空项目警报（Dangling） | **「XX」已停滞 N 天，准备好挑酒店了吗？**（问句式） | 严禁出现「悬空/断流」字眼 |
| 断流保护（Clean Slate） | **轻装重启** | 无「断流/保护期」工业感词汇 |
| 例外日（exceptions） | **假期与出行** | 用户理解的是「我在休假/出差」，不是程序异常 |
| 冷藏池 | **收起的旧想法 · N 条** | 不出现「冷藏」字眼 |

## 5. 界面模块规格：BlockRenderer 渲染矩阵（核心组件形态契约）

四维度叠加：**形态（4，定基础视觉）× 状态（7，定叠加层）× 来源（角标）× 手势（映射既有命令，零新语义）**。本节是「任何块在任何页面渲染」的形态契约——页面编排（哪个页面怎么摆）见 ui-pages。

### 5.1 形态 → 基础视觉

| 形态 | 触发 | 视觉 |
|---|---|---|
| 深度攻坚态 | energy=deep 且电量 high/normal | deepFocus 实底、白字、尾部 `[+15m 呼吸留白]` 锁扣 |
| 微型火种态 | spark（降级/低电量） | 窄胶囊（物理 5min，渲染经 §3.1 钳制 min 44dp）、sparkCapsule 描边、文字切 min_viable_action、无倒计时无进度条 |
| 漫游主题态 | 例外日 或 时长 ≥180min 开放任务 | roamSurface 弱底弱框、起止 `~` 显示（**仅渲染层，数据精确起止**） |
| 庆祝勋章态 | is_celebration | celebration 香槟金微光；过期→archived 淡出，**绝不显红** |

### 5.2 状态 → 叠加层

| 状态 | 叠加 |
|---|---|
| proposed | 虚线边框 + 「提案」角标 |
| confirmed | 实线（默认，无叠加） |
| done | 右下 ✓ 徽章，原色不灰化（完成是正常事，不庆祝不淡化） |
| skipped | ✓ 位换 ⊘，降饱和 |
| missed | 原形态色降饱和 40% + 左侧米黄 4dp 标 + 尾注「未打卡」——与 melted（不渲染）、archived（15% 淡出）拉开三档层次，绝不红 |
| archived | 15% 透明度、禁用交互（断流保护/庆祝过期） |
| melted | **不渲染**（无痕蒸发，仅当日水流摘要提及） |

### 5.3 来源角标

📋 来自清单 ｜ 📌 pinned ｜ 🎫 凭证微标（=`badge` 字段，仅 AI 显式设置者透出——基本只有 booking 类；口信/政策永不上时间轴；渲染 maxWidth 96dp+ellipsis、标题空间优先）｜ 投影=灰底+外部图标且禁用全部手势（点击仅查看）。

### 5.4 手势 → 命令映射（零新语义）

| 手势 | 命令 | 用户可见文案（§4 / ui-pages §9） | 备注 |
|---|---|---|---|
| 轻点 | 打开块浮层（ui-pages §6） | — | |
| 长按 | DegradeBlock(spark) | 「只做 5 分钟」入口；触发提示「已切换为 5 分钟启动版」 | 阻尼动画；human 块不可坍缩 |
| 左滑 | SwapBlock | 抽屉标题「换件轻松的？」 | 候选=待安排池 ±30min 的 light/anywhere 琐事；原任务无痕回池 |
| 右滑 | MeltBlock | 动作标签「**暂缓并收回清单**」；完成提示「已暂缓，放回清单待安排」 | **必须交代去向**，杜绝误删焦虑；绑 plan 时附「已花 X 分钟未入账，补记吗」 |
| proposed 块内 | 确认/否决/改时间 三键 | — | |
| confirmed AI 块内 | +30min 级联顺延 | 按钮「心流专注中 (+30m)」 | human 块仅提示不级联 |
| 日/月视图背景横滑 | 翻页：日 ±1 天 / 月 ±1 月 | —（‹前一天/后一天› 按钮保留为可见出口） | 累计 >60dp（StGesture.pageSwipeDp）触发、不设速度门槛；**周视图内容横向可滚（112dp×7 列）横滑归滚动**、翻周走 ‹› 按钮；块卡片上块手势优先（竞技场内层胜） |
| 清单条目左滑 | UpdatePlan(archived) | 背景标「归档」；提示「已归档「XX」」+动作钮「撤销」 | 过 35% 卡点+触觉；归档 UI 暂不可逆故**必附撤销**（减震器）；**右滑挂账**待「排期」提名流落地接后续；SnackBar 浮动+FAB 净空防动作钮被快记 FAB 遮挡 |
